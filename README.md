# محلل البيانات مصطفى صلاح — نسخة الموقع

دي نسخة من الداش بورد بتشتغل كموقع مستقل برابط باسمك. نسختك على Claude زي ما هي وماتأثرتش.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الموقع كله (البيانات، التنظيف، التقارير، الإحصاء، بايثون، تعلم الآلة، التصدير، المشاريع) |
| `favicon.png` · `apple-touch-icon.png` · `icon-512.png` | أيقونة الموقع في التاب وعلى الموبايل |
| `manifest.webmanifest` | يخلّي الموقع يتثبّت كتطبيق (Install app) |
| `404.html` · `.nojekyll` | ملفات مساعدة لـ GitHub Pages |

---

## الطريقة الأولى: GitHub Pages (مجاني — الرابط `اسمك.github.io`)
1. اعمل حساب على **github.com** (اختار اسم مستخدم زي `mostafa-salah` — هو اللي هيظهر في الرابط).
2. اضغط **New repository** وسمّيه بالظبط: `اسم-المستخدم.github.io` (مثلاً `mostafa-salah.github.io`)، خليه **Public**، واضغط **Create repository**.
3. اضغط **uploading an existing file**، واسحب كل الملفات اللي في الفولدر ده (بعد ما تفك الضغط)، واضغط **Commit changes**.
4. ادخل **Settings ← Pages**، وتحت **Branch** اختار `main` و `/ (root)` واضغط **Save**.
5. استنى دقيقة أو اتنين، والموقع هيفتح على: `https://mostafa-salah.github.io`

> لو سمّيت المستودع اسم تاني (مثلاً `msa-da`) الرابط هيبقى `https://mostafa-salah.github.io/msa-da`.

## الطريقة التانية: Netlify Drop (أسرع — من غير حساب GitHub)
1. افتح **app.netlify.com/drop** وسجّل دخول.
2. اسحب **الفولدر كله** وارميه في الصفحة — الموقع بيتنشر فوراً.
3. من **Site configuration ← Change site name** غيّر الاسم لـ `msa-da` مثلاً، فيبقى الرابط `https://msa-da.netlify.app`.

## دومين خاص بيك (اختياري — زي `mostafasalah.com`)
1. اشتري الدومين من أي موقع (Namecheap / GoDaddy / Google Domains…).
2. **GitHub:** Settings ← Pages ← Custom domain واكتب الدومين، وبعدين في لوحة الدومين ضيف سجلات DNS اللي GitHub بيعرضها لك (A records + CNAME). فعّل **Enforce HTTPS**.
3. **Netlify:** Domain management ← Add a domain واتبع الخطوات.

## تحديث الموقع بعدين
لما أعدّل الداش بورد هبعتلك `index.html` جديد — ارفعه مكان القديم (GitHub: Add file ← Upload files، أو Netlify: اسحب الفولدر تاني في Deploys).

## ملاحظات مهمة
- **المستودع العام على GitHub بيبقى مكشوف للكل**، بما فيه اللوجو والختم المدمجين في `index.html`. لو مش عايز الختم يبقى متاح للعامة، استخدم Netlify (الكود مش بيظهر كمستودع) أو قولّي أعملك نسخة من غير الختم.
- **أي بيانات بترفعها في الموقع بتفضل على جهازك** — مفيش سيرفر بيستقبلها.
- **مفتاح الـ API** بيتحفظ في متصفحك بس ومحدش بيشوفه، بس ماتحطوش على جهاز مشترك.
